# 06 — 12-Month Roadmap & Tracker

Adjust to your semester schedule. Realistic budget: **5–10 hours/week** alongside classes.

## Roadmap

### Months 1–2: Foundations
- [ ] Git & GitHub comfortable (branches, PRs, rebase, resolving conflicts)
- [ ] Polish GitHub profile; create a profile README
- [ ] Set up a blog; publish first post
- [ ] Choose **1 open-source project** to focus on; set it up locally
- [ ] First **2 contributions** (docs/tests/small bug fixes)
- [ ] Join 1–2 communities (club + one online Discord)

### Months 3–4: First real output
- [ ] Start **your own side project** (MVP scoped to ~4 weekends)
- [ ] 3–5 merged PRs in your chosen open-source project
- [ ] Read 2–3 papers from a lab you're interested in; send 5 cold emails
- [ ] Attend 1 hackathon
- [ ] Blog post: "My first open-source contributions"

### Months 5–6: Ship & apply
- [ ] Ship v0.1 of your side project (deployed, with README + demo)
- [ ] Blog post: project write-up
- [ ] Apply to summer programs (GSoC / Outreachy / research internships / REUs)
- [ ] Start working with a lab (even a few hours/week)

### Months 7–9: Go deeper
- [ ] Summer program / research internship / intensive project work
- [ ] Take on a larger issue or feature in your open-source project
- [ ] Help newcomers in that project (answer questions, review small PRs)
- [ ] Blog post: research/internship learnings or paper explainer

### Months 10–12: Lead & share
- [ ] Release v1.0 of your project, or publish it as a library
- [ ] Aim for a research output (poster, workshop paper, open-sourced code)
- [ ] Give a talk (club, meetup, lightning talk)
- [ ] Mentor someone starting out
- [ ] Year-in-review blog post
