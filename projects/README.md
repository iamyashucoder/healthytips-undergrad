# Projects

This section lists important projects: open-source repos to contribute to, projects to build from scratch, and research projects to try.

| File | What's inside |
|------|---------------|
| [open-source-to-contribute.md](open-source-to-contribute.md) | 55+ important open-source projects by area, with links, language, difficulty and how to start |
| [build-from-scratch.md](build-from-scratch.md) | 15 detailed project specs (beginner → advanced) with milestones, stack and what to write about |
| [research-projects.md](research-projects.md) | Paper reproductions, benchmark/dataset ideas and open research problems suitable for undergrads |
| [project-template.md](project-template.md) | A one-page template for planning any new project |

## How to choose

```
Do you want to learn how big, real codebases work?  → open-source-to-contribute.md
Do you want something you own on your résumé?       → build-from-scratch.md
Are you thinking about grad school / research?      → research-projects.md
```

Pick **one from each list** for the year. Contribute to one project, build one, and reproduce one paper. Document all three and write a blog post about each.

## Difficulty key

| Tag | Meaning |
|-----|---------|
| 🟢 Beginner | Comfortable with one language and Git basics |
| 🟡 Intermediate | Have built a few projects; can read unfamiliar code |
| 🔴 Advanced | Comfortable with systems, ML internals, or large codebases |
